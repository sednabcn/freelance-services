## 🎯 Automated Job Finder System

This repository also includes a powerful **Freelancer Opportunity Finder** that automatically:

- 🔍 **Scrapes 4 platforms** - Upwork, Freelancer.com, Guru, PeoplePerHour
- 📧 **Monitors Gmail** - Extracts opportunities from emails
- 🎯 **Smart matching** - Only shows jobs matching your skills (60%+ match)
- 💼 **Business intelligence** - Identifies productizable service patterns
- 📊 **Beautiful reports** - HTML email notifications twice daily
- ⚙️ **Fully automated** - Runs via GitHub Actions

### 🚀 Quick Start

1. **Create Gmail App Password** → [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
2. **Add GitHub Secrets** → Repository Settings → Secrets → Actions
3. **Customize Skills** → Edit `YOUR_SKILLS` in `freelancer_finder.py`
4. **Run Workflow** → Actions → "Freelancer Opportunity Finder" → Run

[**Full Setup Guide →**](SETUP.md) | [**Quick Start Guide →**](QUICK_START.md)
