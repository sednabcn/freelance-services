⚡ Quick Start (5 Minutes)

1. Create Gmail App Password

Visit: myaccount.google.com/apppasswords

Create for "Mail" → "Freelancer Finder"

2. Add GitHub Secrets

Repository Settings → Secrets → Actions

FREELANCER_EMAIL
FREELANCER_PASSWORD
IMAP_HOST: imap.gmail.com
IMAP_PORT: 993
SMTP_HOST: smtp.gmail.com
SMTP_PORT: 587

3. Customize Skills

Edit YOUR_SKILLS in freelancer_finder.py

4. Run First Workflow

Actions → "Freelancer Opportunity Finder" → Run workflow
